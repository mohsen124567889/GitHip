تطبيق المُصلّي AlMusalli — حزمة جاهزة للرفع إلى GitHub

مهم: ارفع محتويات هذا المجلد إلى جذر المستودع، ولا ترفع ملف ZIP نفسه داخل المستودع.

الطريقة من الجوال:
1) فك ضغط AlMusalli-GitHub-Package.zip على هاتفك.
2) افتح مستودع GitHub الخاص بك.
3) اختر Add file ثم Upload files.
4) ارفع المجلد .github ومجلد AlMusalli وملف README-ابدأ-من-هنا.txt مع محتوياتها.
   إذا لم يسمح GitHub برفع مجلدات مباشرة من الهاتف، افتح المجلد ثم ارفع الملفات مع الحفاظ على المسارات؛ أو استخدم GitHub Codespaces/تطبيق GitHub Desktop على كمبيوتر.
5) اضغط Commit changes.
6) افتح Actions ثم Build AlMusalli APK ثم Run workflow.
7) بعد ظهور علامة صح خضراء، افتح تشغيل البناء وانزل إلى Artifacts ثم حمّل AlMusalli-APK.
8) فك ضغط ملف Artifact وثبّت app-debug.apk.

محتويات الحزمة:
- .github/workflows/android.yml: إعداد البناء التلقائي.
- AlMusalli/: مشروع Android الأصلي كاملًا.

ملاحظات النسخة الحالية:
- واجهة عربية داكنة مع لمسات ذهبية.
- اختيار وقت تنبيه يدوي يومي، إشعار، ومحاولة فتح شاشة تنبيه مع رنين.
- ليست نسخة نهائية بمواقيت الصلاة التلقائية؛ لم تُضف بعد وحدات القرآن والأذكار والقبلة.
- ظهور شاشة التنبيه الكاملة يعتمد على صلاحيات وإعدادات Android والشركة المصنعة.
- ملف APK لا يكون جاهزًا إلا بعد نجاح GitHub Actions.
